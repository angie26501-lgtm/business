📲 把黑五美單專頁加到手機桌面
加到桌面後，像 App 一樣一點就開，隨時回來加購、看預購名單


⚠️ 從 LINE 點進來的請先做這步
點右上角 ⋮ 或 ⋯，選「用預設瀏覽器開啟」或「在 Safari 中開啟」，再照下面做




iPhone用 Safari（藍色指南針）
  1. 用 Safari 打開專頁
  2. 點下方 分享 ⬆
    看不到就先點 ⋯
  3. 往下滑，點 加入主畫面
  4. 點右上 新增


iPhone用 Chrome
  1. 用 Chrome 打開專頁
  2. 點網址列旁 分享 ⬆
  3. 往下滑，點 加入主畫面
  4. 點右上 新增


安卓手機小米・OPPO・華碩・三星用 Chrome
  1. 用 Chrome 打開專頁
  2. 點右上 ⋮
  3. 點 加到主畫面
    或「安裝應用程式」
  4. 點 新增


三星用「網際網路」（紫色星球）
  1. 用網際網路打開專頁
  2. 點右下 ≡
  3. 點 新增頁面至
  4. 選 主螢幕 → 新增




桌面沒出現？小米、OPPO、vivo 請到「設定 → 應用程式 → Chrome → 權限」打開「桌面捷徑」，再做一次。


✓ 桌面出現金色「黑五」圖示就完成囉！
